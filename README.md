# Cashly

Cashly —  трекер доходов и целей.

## Что есть
- ручной ввод доходов;
- распределение каждого нового дохода по процентам;
- стартовый капитал только при первом запуске;
- накопительные цели и удобное пополнение;
- история доходов и пополнений целей;
- аналитика стартового капитала и новых доходов;
- темы интерфейса;
- полный локальный сброс данных;
- локальное хранение без подключения банков;
- PWA-режим для браузера;
- Android WebView-проект для личного APK.
