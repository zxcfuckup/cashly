# Cashly Android wrapper

Это нативная Android-обёртка для mobile-first веб-части Cashly.

## Сборка
1. Откройте папку `android/` в Android Studio.
2. Дождитесь Gradle Sync.
3. Запустите на телефоне или эмуляторе.
4. Для магазина: Build > Generate Signed Bundle / APK.

Текущая версия: 1.0.0, versionCode 1.
При следующем релизе увеличивайте `versionCode` и меняйте `versionName`.

Для Google Play обычно нужен подписанный AAB. Для RuStore можно подготовить APK/AAB по актуальным требованиям площадки.
